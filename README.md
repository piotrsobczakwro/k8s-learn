# k8s-learn

A comprehensive learning path for Kubernetes (K8s), covering concepts from basics to advanced topics.

## 📚 Learning Path

### Lesson 1: Basic Concepts
Start your Kubernetes journey by understanding the fundamental concepts and architecture.

**Topics covered:**
- What is Kubernetes?
- Key components (Pods, Nodes, Cluster, Services, Deployments)
- Kubernetes architecture overview
- Use cases and benefits

**Start learning:** [Go to Lesson 1 →](lessons/01-basic-concepts/README.md)

---

## 🎯 Learning Objectives

By following this learning path, you will:
- ✅ Understand Kubernetes core concepts and architecture
- ✅ Learn to deploy and manage containerized applications
- ✅ Master Kubernetes networking and storage
- ✅ Gain hands-on experience with real-world scenarios
- ✅ Develop best practices for production deployments

## 🚀 Getting Started

1. Start with [Lesson 1: Basic Concepts](lessons/01-basic-concepts/README.md)
2. Follow the lessons in order
3. Complete exercises and examples in each lesson
4. Practice with hands-on labs

## 📖 Prerequisites

Before starting, you should have:
- Basic understanding of containers (Docker)
- Familiarity with command-line interfaces
- Basic networking concepts
- A computer with internet access
