# Lesson 2: Getting Started with Kubernetes

Welcome to the hands-on introduction to Kubernetes! This lesson will help you set up your environment and deploy your first applications.

## Table of Contents

1. [Installation and Setup](01-installation.md)
2. [kubectl Basics](02-kubectl-basics.md)
3. [Your First Pod](03-first-pod.md)
4. [First Deployment](04-first-deployment.md)

## Learning Objectives

By the end of this lesson, you will be able to:
- Set up a local Kubernetes environment
- Use kubectl to interact with a cluster
- Create and manage Pods
- Deploy applications using Deployments
- Expose applications using Services
- Understand basic YAML manifests

## Prerequisites

- Completed [Lesson 1: Basic Concepts](../01-basic-concepts/README.md)
- Docker installed on your machine
- Basic command-line skills
- Text editor (VS Code, vim, nano, etc.)

## Estimated Time

Approximately 3-4 hours including hands-on practice.

## What You'll Build

Throughout this lesson, you'll:
1. Set up a local Kubernetes cluster
2. Deploy a simple web application
3. Scale the application
4. Expose it to the outside world
5. Update the application with zero downtime
