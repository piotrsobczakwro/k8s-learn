# Lesson 4: Configuration and Storage

Learn to manage application configuration and persistent data in Kubernetes.

## Table of Contents

1. [ConfigMaps](01-configmaps.md)
2. [Secrets](02-secrets.md)
3. [Volumes](03-volumes.md)
4. [Persistent Volumes](04-persistent-volumes.md)

## Learning Objectives

- Externalize configuration using ConfigMaps
- Securely manage sensitive data with Secrets
- Understand different volume types
- Use Persistent Volumes for stateful applications
- Configure dynamic storage provisioning

## Prerequisites

- Completed [Lesson 3: Core Workloads](../03-core-workloads/README.md)
- Understanding of Pods and Deployments

## Estimated Time

4-5 hours including hands-on practice.
