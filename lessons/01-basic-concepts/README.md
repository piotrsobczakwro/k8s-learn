# Lesson 1: Basic Kubernetes Concepts

Welcome to the first lesson in your Kubernetes learning journey! This lesson covers the fundamental concepts you need to understand before diving deeper into Kubernetes.

## Table of Contents

1. [What is Kubernetes?](01-what-is-kubernetes.md)
2. [Key Components](02-key-components.md)
3. [Architecture Overview](03-architecture-overview.md)
4. [Use Cases and Benefits](04-use-cases-and-benefits.md)

## Learning Objectives

By the end of this lesson, you will be able to:
- Define what Kubernetes is and why it exists
- Identify and describe the key components of Kubernetes
- Understand the high-level architecture of a Kubernetes cluster
- Recognize common use cases where Kubernetes provides value
- Explain the benefits of using Kubernetes for container orchestration

## Prerequisites

- Basic understanding of containers (Docker)
- Familiarity with command-line interfaces
- Basic networking concepts

## Estimated Time

Approximately 2-3 hours to complete all materials in this lesson.
